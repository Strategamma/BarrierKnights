# UI/UX Vision

Mobile is board-first. Compact screens up to 960px and coarse-pointer touch devices use the mobile layout, including wide phones and tablets. Portrait mode uses a dense top-control/board/bottom-control stack with 48px primary touch targets and the board sized from both available width and the live Visual Viewport height. Landscape mode centers the largest possible board between narrow vertical player panels and retains 42px touch targets; bot status occupies the opposite side from human controls. Touch wall placement uses a persistent ghost preview with explicit Place/Cancel controls, and Undo remains available in the header. Card results are temporarily pinned at the visible top, safe-area insets are respected, and New Game remains reachable. The logo has a visible text fallback if its SVG asset fails.

Presentation uses a dark glass-and-metal tournament aesthetic with blue/gold lighting, restrained grid texture, clearly selected actions, animated active-player emphasis, card reveals, turn flashes, smooth pawn travel, pickup bursts, wall place/break impacts, and winner-colored confetti. Effects remain non-blocking and `prefers-reduced-motion` disables decorative movement.

Navigation uses plain action labels, persistent back routes, short helper copy, and explicit Play again/Change mode choices. Nearby Wi-Fi explains same-network setup, honestly labels the SSID as browser-private, and shows only Barrier Knights users seen by the gateway. Its lobby confirms both generated names/colors before the host starts, using a soft radar/pulse treatment that respects reduced motion. Decadence Inc is the visible parent destination from setup, gameplay, and victory.
